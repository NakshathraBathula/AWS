# 🌟 WEEK-4: AMAZON S3 COMPLETE EXPERIMENT

---

# ✅ PART 1: Create S3 Bucket & Enable Public Access

---

## 🔹 Step 1: Create Bucket

1. Login to **AWS Console**
2. Go to **S3**
3. Click **Create bucket**
4. Enter:

   * Bucket name (globally unique)
   * Select Region
5. Under **Block Public Access**
   ❌ Uncheck *Block all public access*
   ✔ Acknowledge warning
6. Click **Create bucket**

✔ Bucket created

---

## 🔹 Step 2: Upload Object

1. Open bucket
2. Go to **Objects**
3. Click **Upload**
4. Add file (example: image.jpg)
5. Click **Upload**

✔ File uploaded

---

## 🔹 Step 3: Make Object Public (ACL Method)

1. Click uploaded object
2. Go to **Permissions**
3. Click **Edit ACL**
4. Under Public Access:
   ✔ Everyone → Read
5. Save

✔ Object accessible in browser

---

# ✅ PART 2: Enable Versioning

---

## 🔹 Step 1: Enable Versioning

1. Open bucket
2. Go to **Properties**
3. Scroll to **Bucket Versioning**
4. Click **Edit**
5. Select **Enable**
6. Save

✔ Versioning enabled

---

## 🔹 Output Scenario

### Upload file (report.pdf)

→ Version ID created automatically

### Upload same file again

→ New version created
→ Old version preserved

### Delete file

→ Delete marker created
→ Old versions still exist

✔ Data not permanently lost

---

# ✅ PART 3: Cross-Region Replication (CRR)

---

## 🔹 Prerequisites

✔ Versioning enabled on both buckets
✔ Source & destination buckets in different regions

---

## 🔹 Step 1: Create Destination Bucket

1. Create new bucket
2. Select different region
3. Enable Versioning

---

## 🔹 Step 2: Create Replication Rule

1. Open Source bucket
2. Go to **Management**
3. Click **Replication rules**
4. Click **Create rule**

---

## 🔹 Configure Rule

* Rule name
* Apply to all objects
* Destination bucket → select new bucket
* Choose AWS-managed role
* Save

✔ Replication activated

---

## 🔹 Output

Upload file to source bucket
→ Automatically appears in destination bucket

✔ Replication successful

---

# ✅ PART 4: Static Website Hosting

---

## 🔹 Step 1: Upload Website Files

Upload:

* index.html
* error.html

---

## 🔹 Step 2: Enable Static Hosting

1. Go to **Properties**
2. Scroll to **Static website hosting**
3. Click **Edit**
4. Enable
5. Enter:

   * Index: index.html
   * Error: error.html
6. Save

✔ Website endpoint URL generated

---

## 🔹 Step 3: Enable Public Access

### Option 1: ACL Method

* Bucket ACL → Everyone → Read
* Object ACL → Everyone → Read

### OR

### Option 2: Bucket Policy Method

Add:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::bucket-name/*"
    }
  ]
}
```

---

## 🔹 Step 4: Access Website

Open:

```
http://bucket-name.s3-website-region.amazonaws.com
```

✔ Website loads

# ✅ Common Errors & Solutions

| Error         | Reason                      |
| ------------- | --------------------------- |
| 403 Forbidden | No public read permission   |
| 404 Not Found | index.html missing          |
| AccessDenied  | Block Public Access enabled |
